# One Line of Earned Pride

One line, 240 characters max — a quiet, earned moment of pride for someone in the scene, judged on genuine effort and freshness. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
